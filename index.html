About

I am an M.S. student in Electrical Engineering and Computer Sciences at UC Berkeley, where I also received B.A. degrees in Computer Science and Applied Mathematics (Highest Distinction). I do research in the Sky Computing Lab, advised by Prof. Joseph Gonzalez and Prof. Ion Stoica. My interests are LLM agents, reinforcement learning for LLMs, and tool use.

Research

  • D-Skill: Distilling Teacher Knowledge through Agent Skills2026
    Distills paired teacher–student agent trajectories into reusable natural-language skills, closing 82–95% of the teacher–student gap at 5.7–8.2× lower inference cost. Project lead; in submission to ICLR 2027.
  • I-PTC: Interactive Programmatic Tool Calling2026
    A stateful, notebook-style tool-calling framework for LLM agents, plus PTC-Bench, a 240-task benchmark for long-horizon tool use. Project lead; NeurIPS 2026.
  • RLEM: Reinforcement Learning for External Memory2025 – 2026
    Trainable external memory with step-wise GRPO, letting LLMs handle contexts up to ~1M tokens.
  • SkyRL-Agent: Computer Use Agent Post-Training2025
    Async, distributed RL training for computer-use agents, scaling from 8 to 128 environments.
  • SkyRL-SQL: Multi-turn SQL Data Agents via RL2025
    Multi-turn GRPO training for SQL agents that improves Spider accuracy by 7% with only 600 examples.
