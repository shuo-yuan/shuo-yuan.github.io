# shuo-yuan.github.io

Personal website for Shuo Yuan, served by GitHub Pages.

- `index.html` — homepage
- `education.html` — degrees and coursework
- `life.html` — life: snowboarding, soccer, photography, traveling (world map)
- `cs180.html` — COMPSCI 180 project portfolio (projects in `0/` – `5/`)
- `courses.html` — redirects old links to `education.html`
- `assets/` — shared `style.css`, `theme.js` (light/dark toggle), `photo-stack.js` (homepage photos), `travel-map.js` (Life page map), photos, CV
